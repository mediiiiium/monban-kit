# 人の側：Bitwarden の個人金庫を普段使いにする

作成日: 2026-11-12
前提：[muse-note-two-vaults.md](muse-note-two-vaults.md)（人は個人金庫と自動入力で、門番は通さない）、README の「2つの置き場と振り分け」

## 決まり

- 人の側は Bitwarden を普通に使うだけ。プロジェクトとして残すのは、導入の手順と結果だけ
- 足す決まりは1つ：エージェントに渡すかもしれない秘密は、個人金庫に入れず Secrets Manager（組織 `monban`）に置く
- パスワードの書き出しファイル（CSV など）、マスターパスワード、リカバリーコードは、このリポジトリにも会話にも出さない。結果に書くのは「やった・やっていない」と、つまずいたところだけ
- 画面の名前はアプリの版で変わる。手順と違ったら、やった人が直す

## 手順

### 1. アカウントと2段階認証（済み）

- 2026-11-10 に済んだ（[first-secret-trial.md](first-secret-trial.md) の「準備」）。アカウントは Secrets Manager の無料版の登録から作り、同じアカウントに個人金庫がある。2段階認証は認証アプリ

### 2. リカバリーコードを金庫の外に置く（済み）

- 2段階認証の画面からリカバリーコードを出して控える
- 置き場は Bitwarden の外にする（金庫に入れると、金庫に入れないときに使えない）。紙に書いて手元に置く、など
- 2026-11-12 に済んだ（置き場はここに書かない）

### 3. Mac で自動入力を使う

- 普段使うブラウザに Bitwarden の拡張機能を入れ、ログインする
- 解錠はマスターパスワードのほかに、生体認証（Touch ID）でもできるようにする。金庫が鍵をかけるまでの時間（タイムアウト）を決める
- どこか1つのサイトで、自動入力でログインしてみる

### 4. スマホで自動入力を使う

- Bitwarden のアプリを入れ、ログインする
- OS の自動入力の設定で Bitwarden を選ぶ（iPhone は「設定」の「自動入力とパスワード」。Android は自動入力サービス）
- どこか1つのアプリかサイトで、自動入力でログインしてみる

### 5. ほかの置き場から移す（する場合だけ）

- 移す元：Chrome のパスワード、iCloud キーチェーン（「パスワード」アプリ）など
- 多くは CSV に書き出して、Bitwarden のウェブ金庫の読み込みで入れる
  - CSV は平文。このリポジトリの外の一時的な場所に置き、読み込んだらすぐ消す（ゴミ箱も空にする）
  - エージェントが動いている間に書き出さない。同じユーザーのエージェントは CSV を読める
- 移した後、元の置き場のパスワードを消すかは決めてから進める（両方に残すと、変えたときに片方が古くなる）
- 移すときに振り分ける：エージェントに渡すかもしれないもの（API キーなど）は個人金庫に入れず、Secrets Manager に置く

### 6. 1週間、普段使いで使う

- 困ったところを結果に書く（自動入力が出ないサイト、解錠の手間、など）

## 結果

- 1・2：済み（2026-11-10、2026-11-12）
- 3〜6：まだ

## これで防げないこと

- 個人金庫は、マスターパスワードで開けば全部見える。出し分けはできない
- 解錠中の金庫は、同じユーザーで動くエージェントから守れない前提で考える（ブラウザの拡張機能やアプリの中身を、同じ uid のプロセスが覗く道を確かめていない）。だからエージェント用の秘密は個人金庫に置かない
- 2段階認証の認証アプリの端末とリカバリーコードを両方なくすと、アカウントに入れなくなる
