## 元の置き場

- Chrome：消す側が素直。残す理由が一番薄く、「ついでに保存される」事故の元でもあるので、消すのと、これから保存しない設定（オフ）をセットにする
  - 注意：Bitwarden の拡張機能を入れたのは、まだ1つのプロファイルだけ。拡張機能を入れたプロファイルから順に、「入れる → Chrome 側を消す」を対にする
- 「パスワード」アプリ：パスワードの項目だけ消す。手順4の役割分担（パスキー・確認コード・Wi-Fi は「パスワード」に残す）と合う
  - 効き目：自動入力で候補が2つ出る混乱が消える。「片方だけ古くなる」の元が消える
  - 手順：よく使うサービスで、Bitwarden 側からログインできるのを確かめてから消す。586 件を全部確かめるのは現実的でないので、普段使いの上位だけで十分
