# Mac での自動入力を軽くする設定（1週間の試用の準備）

作成日: 2026-11-10
前提：Mac＋ブラウザ拡張。Bitwarden の公式ヘルプで確認した内容。

## 設定の一覧

1. 拡張機能の「設定」→「自動入力」
   - 「入力欄に自動入力の候補を表示」（Show autofill suggestions on form fields）をオフにする
   - 「ページ読み込み時に自動入力」もオフにする
2. ブラウザ側
   - Bitwarden を既定のパスワード管理にする（Make Bitwarden your default password manager）
   - ブラウザ自身のパスワード保存と自動入力を切る（公式の推奨。ブラウザの機能が Bitwarden の自動入力の邪魔をするため）
3. 入力は `⌘⇧L` で行う
   - 公式も「最も速い方法の一つ」としている
   - 同じサイトに複数のアカウントがあるときは、もう一度押すと切り替わる
   - ロック中に押すと解除のウィンドウが開き、解除するとそのまま入力まで進む
   - ワンタイムコードは、Bitwarden に保存している項目なら入力後にクリップボードへコピーされる（保存は Premium、年 $19.80 の機能。無料版では別のアプリでコードを出す）
4. Touch ID で解除する
   - Bitwarden のデスクトップアプリを入れて、ログインしたまま起動しておく（拡張機能だけでは Touch ID は使えない）
   - デスクトップアプリ：「設定」→「セキュリティ」→「Touch ID で解除」をオン
   - 拡張機能：「設定」→「アカウントのセキュリティ」→「生体認証で解除」をオン
   - 「連携するネイティブアプリとの通信」の許可を求められたら許可する
   - 金庫のロックまでの時間を少し長めにする
5. Safari を使うなら、Safari のサイドバー表示のショートカットを別のキーに変える（`⌘⇧L` と重なっていて、自動入力が動かないため）

## この設定でも変わらないこと

- ブラウザ以外のアプリのパスワード欄には、候補が出ない
  - Mac 全体の自動入力で使えるのはパスキーだけ。それも順番に広げている途中
  - パスワードとワンタイムコードは、まだ下書きの PR（bitwarden/clients #23740）の段階
- ブラウザ以外のアプリでは、Raycast の Bitwarden 拡張で検索してコピーする
